# Task 2: Explore the Linux Folder Tree



The `/bin` directory contains essential commands used by Linux. On modern Ubuntu systems, `/bin` is commonly linked to `/usr/bin`. The `/usr/bin` directory contains many standard user commands and programs. The `/usr/local/bin` directory is commonly used for locally installed programs that are not managed as part of the standard system packages. These directories help organize Linux commands and make them easier to access.
